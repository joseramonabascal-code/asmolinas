# AS MOLINAS — Tienda en Línea

Tienda de productos naturales de calidad: tés, especias, molidos, sales y deshidratados.

**Sitio web:** [asmolinas.com](https://asmolinas.com)  
**Contacto:** ventas@asmolinas.com

## Cómo usar

Abrir `index.html` en el navegador o visitar la URL de GitHub Pages.

## Configuración de PayPal

1. Ve a https://developer.paypal.com/dashboard/
2. Crea una App y copia el **Client ID**
3. En `index.html`, reemplaza `TU_CLIENT_ID_AQUI` con tu Client ID real

## Configuración de WhatsApp

En `index.html`, reemplaza `521TUNUMERO` con tu número de WhatsApp (formato: `521XXXXXXXXXX`).

## Tecnologías

- HTML5 / CSS3 / JavaScript (sin dependencias externas)
- PayPal SDK para pagos en MXN
- Google Fonts (Playfair Display, Nunito)
